# Google AI Overview for "claude code pricing" (US, desktop, English), saved 2026-10-21 16:19 UTC from the DataForSEO SERP response

Claude Code is included in paid [Anthropic Claude Plans](https://claude.com/pricing) , starting at **$17 to $20 per month** on the Pro tier . Pricing scales across individual, team, and API pay-as-you-go options depending on how many tokens or sessions you use.[[1]](https://claude.com/pricing)[[2]](https://www.finout.io/blog/claude-code-pricing-2026)

### Subscription Plans

- **Free ($0/mo):** Does not include Claude Code.
- **Pro ($17/mo billed annually or $20/mo monthly):** Includes baseline Claude Code access, sharing a session usage limit with web and desktop chat.
- **Max 5x ($100/mo, monthly only):** Offers 5x the usage allowance of Pro for regular individual developers.
- **Max 20x ($200/mo, monthly only):** Offers 20x the usage allowance of Pro with heavier agent runs and Opus access.[[1]](https://claude.com/pricing)[[2]](https://www.softr.io/blog/claude-code-pricing)[[3]](https://www.datacamp.com/tutorial/how-to-use-claude-code-for-free)[[4]](https://www.ssdnodes.com/learn/claude-pro-price-and-limits)[[5]](https://www.morphllm.com/claude-code-pricing)[[6]](https://www.finout.io/blog/claude-code-pricing-2026)

### Team and Enterprise Plans

- **Team Standard ($20/seat/mo annual or $25/mo monthly):** Includes 1.25x Pro session capacity.
- **Team Premium ($100/seat/mo annual or $125/mo monthly):** Includes 6.25x Pro session capacity for power users.
- **Enterprise ($20/seat/mo billed annually + usage):** Adds SCIM, audit logs, and custom retention, with usage billed at API rates.[[1]](https://www.finout.io/blog/claude-code-pricing-2026)[[2]](https://coworker.ai/blog/claude-code-pricing)[[3]](https://www.softr.io/blog/claude-code-pricing)

### API Pay-As-You-Go

- **Anthropic Console / API:** Billed directly per token (input, output, and prompt caching) if you prefer not to use a flat-fee subscription.[[1]](https://www.softr.io/blog/claude-code-pricing)[[2]](https://www.finout.io/blog/claude-code-pricing-2026)
