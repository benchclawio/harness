Context engineering is "the practice of designing, structuring, and optimizing everything fed into a large language model (LLM) during inference, including system prompts, retrieved data, tools, and conversation history, to maximize accuracy and reliability".

While prompt engineering focuses strictly on how you phrase a single question, context engineering manages the entire environment and data pipeline surrounding the model.

Core components: System Prompts; Retrieval-Augmented Generation (RAG); Tools and Metadata; Memory and History.

Key techniques: Write (offload data outside the active window using scratchpads and memory systems); Select (retrieve only the most relevant tokens, tools and facts for each step); Compress (summarise long histories or trim redundant text); Isolate (split context across sub-agents or sandboxes).
